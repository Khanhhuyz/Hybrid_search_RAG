GRAG v0.1.0-alpha

Mini Semantic Search & Knowledge Graph RAG System

Created by QuiNC • Built in < 2 hours (Experimental Prototype)

Overview

A personal side project exploring a lightweight RAG system combining vector search with a knowledge graph to query uploaded documents with verifiable citations.

How It Works

1. Ingestion & Structuring

Extracts document text, splits it using Markdown header hierarchy (`#`, `##`), and extracts entity-relationship triples via LLM.

2. Dual Retrieval

Executes dense vector search on Qdrant Cloud alongside 2-hop neighborhood expansion on the NetworkX Knowledge Graph.

3. RRF Reranking

Blends vector similarity scores with graph node weights using Reciprocal Rank Fusion (RRF) algorithm.

4. SSE Streaming & Inspection

Streams answer tokens in real-time. Citations link directly to a slide-over panel for raw chunk inspection.

Core Tech Stack

  • Frontend: Next.js 15, Tailwind CSS, Lucide Icons, D3.js Force Visualizer.
  • Backend: FastAPI (Async), NetworkX Graph, SQLAlchemy.
  • Vector DB: Qdrant (Dual mode: Local file or Qdrant Cloud).
  • Inference: Local Ollama (`nomic-embed-text` embeddings, `llama3.2` LLM).
  • Orchestration: Docker Compose support included.

Key API Endpoints

  • POST /api/v1/documents/upload — Ingest PDF/DOCX/TXT files
  • POST /api/v1/chat/stream — SSE token streaming response
  • GET /api/v1/graph/visualize — Graph D3 nodes & edges JSON
  • GET /api/v1/documents/{id}/file — Raw document file stream
